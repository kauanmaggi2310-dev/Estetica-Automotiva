# LavaJet Estética Automotiva

Landing page responsiva para estética automotiva **a domicílio**, com hero em vídeo e identidade amarela.

## Serviços

- Estética automotiva
- Higienização de estofados
- Lava-rápido
- Atendimento no endereço do cliente

## Publicação

- Produção: https://esteticaato.vercel.app
- Arquivos estáticos: `dist/`
- Configuração da Vercel: `vercel.json`

O vídeo do hero usa um clipe automotivo livre do Pexels, sem logotipo da LavaJet.
